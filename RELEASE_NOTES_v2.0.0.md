# Emoji Studio for Slack v2.0.0 Release Notes

## Major New Features

### Bulk Emoji Reactions
React to any Slack message with multiple emojis at once! Click the ⚡ button to open the bulk reaction picker, select as many emojis as you want, and apply them all with a single click.

- **Toolbar Button**: Find the ⚡ button in the message toolbar (alongside bookmark, more actions, etc.)
- **Reaction Bar Button**: Also available next to the "Add reaction" button below messages
- **Visual Selection**: Selected emojis appear as removable chips so you can see exactly what you're adding
- **One-Click Apply**: Hit "React" to add all selected emojis to the message instantly

### Emoji Info Tooltip
Hover over any reaction on a message to see detailed information:

- **Creator Info**: See who added the emoji to your workspace
- **Creation Date**: Know when the emoji was originally added
- **Quick Link**: Click to view the full emoji details in Emoji Studio

## Improvements

- Improved UI styling to match Slack's native look and feel
- Better hover states and visual feedback
- Success confirmation after bulk reactions complete

## What's Next

This is a major update focused on making emoji reactions faster and more powerful. We're continuing to improve the Slack integration experience.
